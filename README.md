## ✨ About the Project

**Tarot Mística** is an experimental, browser-based tarot experience that blends  
symbolism, motion, and intuition through real-time interaction.

Built with modern web technologies, the app uses gesture-driven states, 3D visuals,  
and atmospheric design to create a contemplative digital ritual rather than a  
traditional “reading” interface.

This project explores:
- Digital spirituality
- Embodied interaction (gesture → meaning)
- Mood, pacing, and presence in UI design

---

## 🃏 Features

- Interactive 3D tarot deck rendered in the browser
- Gesture-driven flow (shuffle, draw, reveal)
- Custom-designed card backs and visual language
- Particle and light effects for atmosphere
- Spanish-first narrative and instructions

---

## 🛠 Tech Stack

- **React + TypeScript**
- **Three.js** via `@react-three/fiber`
- **@react-three/drei**
- **Vite** for development and builds
- **Netlify** for deployment
